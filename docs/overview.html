PCIe link classes (rdnactl topo)

      

        
ClassPath between two GPUsFor TP

        
PIXSame PCIe switchBest. Put a TP group here.

        
PXBSeveral switches, no root complexGood.

        
PHBThrough one root complexSlower all-reduce.

        
SYSAcross root complexes / socketsAvoid for TP; check P2P.

      

      
When a recipe does not pin HIP_VISIBLE_DEVICES, rdnactl picks GPUs of the right arch that share a switch.

    

  


  

    
How a recipe becomes a launch

    

      
_base.yaml (fragment)
env:
  VLLM_ROCM_USE_AITER: "0"
  GPU_MAX_HW_QUEUES: "2"
args:
  dtype: float16

      
27b-awq.yaml
extends: [_base, _attn-fa]
model:
  source: org/Qwen3.8-27B-AWQ
requires: {arch: [gfx1030], gpus: 4}
args:
  tensor-parallel-size: 4
  enable-prefix-caching: true

      
--set overrides
--set args.max-model-len=32768
--set env.GPU_MAX_HW_QUEUES=4

      
plan (rdnactl recipe plan)
export GPU_MAX_HW_QUEUES=4
export HIP_VISIBLE_DEVICES=2,3,4,5
vllm serve org/Qwen3.8-27B-AWQ \
  --attention-backend RDNA_ATTN \
  --dtype float16 \
  --enable-prefix-caching \
  --max-model-len 32768 \
  --tensor-parallel-size 4
